# Athlé 632 Studio

Générateur de visuels officiels pour l'Athlé 632. Créez des posts et des stories Instagram en quelques secondes.

## Fonctionnalités

- **Formats multiples** : Post (1:1) et Story (9:16).
- **Types de Story** : Information ou Liste de Résultats.
- **Secteurs personnalisés** : Piste, Athlé Santé / Marche Nordique, Route / Trail.
- **Logo personnalisable** : Utilisez le logo officiel ou téléchargez le vôtre.
- **Export PNG** : Téléchargement instantané en haute résolution.

## Installation Locale

Si vous avez exporté ce projet depuis Google AI Studio et que vous souhaitez le faire tourner localement :

1. Installez les dépendances :
   ```bash
   npm install
   ```

2. Lancez le serveur de développement :
   ```bash
   npm run dev
   ```

3. Ouvrez votre navigateur sur `http://localhost:3000`.

## Déploiement sur GitHub Pages

Ce dossier est prêt à être envoyé dans un dépôt GitHub.

1. Créez un nouveau dépôt GitHub.
2. Envoyez tout le contenu de ce dossier dans le dépôt.
3. Dans GitHub, allez dans `Settings` > `Pages`.
4. Dans `Build and deployment`, choisissez `GitHub Actions`.
5. Poussez sur la branche `main` : le site sera construit et publié automatiquement.
